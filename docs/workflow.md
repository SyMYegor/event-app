# Git Workflow in VS Code
Author: Yegor Sadkovyi, group 491.

## Sequence
Create a file, save it, select Stage Changes, enter a commit message,
select Commit and use Push or Publish Branch.

## Branches
feature-style changes the page appearance and heading.
feature-docs maintains documentation.
Merge Branch integrates completed work into main.

## Remote interaction
Push shares local commits. Fetch updates remote history without changing
working files. Pull integrates remote changes into the current branch.

## Recovery
Revert creates a new commit that reverses a selected commit.
Undo Last Commit removes the latest local commit and keeps staged changes.
Discard Changes removes an uncommitted edit in a tracked file.
